# בוט מסירות → טלגרם

כל 15 דקות הבוט בודק מודעות חדשות למסירה באתר **אגורה** (agora.co.il), ושולח לטלגרם כל מודעה שמתאימה:

- ספה בצורת ר'
- תנור משולב כיריים גז
- מייבש כביסה
- שולחן סלון
- שולחן אוכל וכיסאות
- ציוד לחצר

רק מודעות מגוש דן, מהשרון ומהשפלה (עד 45 דקות מתל אביב ומראש העין). כשבמודעה כתובות מידות, הבוט בודק אם הפריט נכנס לבית (✅ או ⚠️).

- **הגדרות** (ערים, פריטים, מידות): `config.json`
- **מודעות שכבר נבדקו:** `state.json` (מתעדכן לבד)

יד2 חוסם בוטים, ולכן הבוט בודק רק את אגורה.
