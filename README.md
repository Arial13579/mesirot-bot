# בוט מסירות → טלגרם

כל 10 דקות הבוט בודק מודעות חדשות למסירה באתר **אגורה** (agora.co.il), ושולח לטלגרם **כל מודעה באזור**, חוץ ממכונות כביסה, מקררים וספות.

מודעות על תנור משולב כיריים גז, מייבש, שולחנות וציוד לחצר מקבלות כותרת משלהן, ובתנור ובחצר הבוט בודק גם מידות (✅ או ⚠️).

רק מודעות מגוש דן, מהשרון ומהשפלה (עד 45 דקות מתל אביב ומראש העין).

- **הגדרות** (ערים, מה לא לשלוח `never`, מידות): `config.json`
- **מודעות שנבדקו ורשימת המנויים:** `state.enc` (מוצפן, מתעדכן לבד)

יד2 ופייסבוק חוסמים בוטים, ולכן הבוט בודק רק את אגורה.

## טלגרם
- `/link`: קישור הצטרפות למישהו נוסף (רק מנויים מקבלים אותו).
- `/stop`: הפסקת ההודעות.
